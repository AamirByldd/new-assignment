# Products App

A React app that fetches products from [DummyJSON](https://dummyjson.com/) and displays them as cards with search and pagination.

## Features

- Fetches 100 products from the DummyJSON API
- Search products by title or category
- Pagination (9 products per page)
- Responsive grid layout

## Tech Stack

- React
- Vite
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```
